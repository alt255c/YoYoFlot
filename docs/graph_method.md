# T18 · совместные события исходного набора

Вход — те же неизменные сегменты T13. Допуск требует graph_eligible, исходный
UTC вылета, полный номер рейса и оба airport_id. Ключ события: точный UTC,
номер, origin, destination. Дата/маршрут/номер без времени не доказывают
единственный экземпляр рейса. Сегменты без допуска остаются в общей карте.

Внутри события один person_id учитывается один раз. Ребро — минимум два
разных дня совместных событий. Сохраняются shared_events, shared_days,
сумма 1/(число участников события−1), список event_ids. Таблица event_members
раскрывает событие до person_id/segment_id, затем до исходного anchor_travel_id
и опциональных segment_links. Вес обратной наполняемости — описательная
характеристика, не p-value и не доказательство редкости.

Максимум 1000 участников на расширяемое событие, исключения считаются явно.
Прогноз расширения >20 млн пар означает unavailable для всего графа,
а не молчаливую усечённую таблицу. Graph status/ограничения сохраняются.

M07 не добавляет голос к основному рейтингу: калибровка статистической
значимости совместности с учётом фона и независимое ревью ещё нужны.
Граф в карточке показывает наблюдаемые повторения, не объявляет людей
соучастниками. Предыдущий сложный synthetic null-эксперимент не переносится
на исходные данные без проверки предпосылок.
