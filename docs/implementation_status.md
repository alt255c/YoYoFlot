# T16 — 17.10.2026, версия 0.7.0

По указанию пользователя T16 возобновлена в `reape/T16` от актуального `develop`.
Реализованы CLI `run`/`scripts/run_t16.py`, последовательное ядро readers →

исходные raw при этом не объявляются перепроверенными.

лишь первый столбец составного ключа. Теперь проверяется полный ключ;
настоящие дубли по-прежнему блокируют выпуск. Для spill T14 выделен собственный
временный каталог. `.gitattributes` закрепляет CRLF для справочника, сохраняя
прежние значения и опубликованный SHA-256.

**300 тестов проходят**, включая прерывание/возобновление, повреждённый кэш,
изменение входа при неизменных размере/mtime, смешанный upstream, старые снимки,
все семь учебных источников и CLI из другой рабочей папки. Полного реального
T16/RSS-замера и независимого ревью здесь нет. T15, модель и сайт не запускаются;
T21 pass не заявляется. [Инструкция](usage.md), [карточка](../tasks/T16.md),

## Свидетельства

- validation/input_census.json: независимые счётчики и SHA-256 всех шести входов.
- validation/real_runs.json и logs/: полные CLI-прогоны, время и RSS.
- validation/structural_checks.json: схемы, ключи, связи, полнота provenance.
- validation/source_audit_checks.json: 912 сравнений исходных/выходных значений.
- validation/sirena_audit_20.csv: 20 строк по всему файлу и все 20 колонок.
- validation/workbook_inventory.csv и workbook_coverage.csv в результатах:
  независимый перечень книг и покрытие каждого листа.
- validation/field_coverage.json: заполненность ключевых полей и точность дат.
- validation/pytest.xml и fixture_runs.json: тесты и семь синтетических прогонов.

Сверка источников выполнена программой и проверена ассистентом; это не подпись
названных в заданиях людей. Технические критерии T04–T10 подтверждены, а
общекомандное согласование контракта и подпись проверяющих остаются за командой.
Задачи T01/T02/T11 и далее не входят в эту поставку. Python >=3.10 поддерживается
объявленными зависимостями и синтаксисом; запуск проверен на 3.12.14, не на 3.10.

подготовки наблюдений при лимите DuckDB 512MB; успешный полный T13 не заявлялся.

Конфликтные DOB-свидетельства выделяются без накопления списков. Контракты,
решения и все исходные ссылки сохранены. Добавлены регрессия границ порций и
синтетический воспроизводитель на 2 746 977 наблюдений / 3 207 435 идентификаторов.
