# Объяснимая модель правил

Isolation Forest, его обучение, артефакты и зависимости удалены. Текущий
рейтинг — модель правил с настраиваемыми весами из `configs/scoring.yaml`.
Метки классов не предоставлены; балл не является вероятностью правонарушения.
Accuracy, precision/recall и качество классификации не заявляются.

M01–M03 описывают частоту поездок, быстрые возвраты и повторяемость маршрутов.
Их вклад — вес × min(3, значение / порог). Остальные подготовленные факторы
проверяют исходные документы, контакты и совместные поездки; при срабатывании
используется заданный вес. Порог, значение, доступность, вклад и свидетельства
сохраняются для каждого профиля. Недоступность не превращается в срабатывание.

Общие исходные основания не учитываются дважды. Из конфликтующих вкладов
выбирается набор с максимальной суммой без прямого пересечения оснований.
Сортировка: сумма по убыванию, затем `person_id`. Вес 0 отключает вклад, сохраняя
результат проверки фактора. Число факторов показывается отдельно.

Сборка использует исходный архив преподавателя, проверяет контрольные суммы,
обрабатывает все семь источников и сохраняет полные связи профилей с ними.
Новые пассажиры, перелёты, метки или значения пропусков не генерируются.
Сайт и CSV/JSON читают один подготовленный снимок. После изменения весов
нужна повторная сборка; совместимые промежуточные результаты используются снова.

Полный пересчёт исходного набора этой ревизией в среде проверки не выполнялся.
Старые численности и отчёты в docs/validation относятся к прежним версиям.
