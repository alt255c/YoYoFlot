# T19 · Isolation Forest на исходном наборе

IF реально обучается на trip_rate_30_days, quick_return_share и
repeated_route_share из тех же принятых T13-профилей, где доступны все три
группы. Имена, документы, страны и ID не являются числовыми признаками.
Пропуски исключаются с сохранением статуса; импутации и вымышленных строк нет.

Детерминированное разделение по SHA-256(person_id), первые 32 бита mod 10:
0–5 training, 6–7 calibration, 8–9 holdout. До 100000 training-профилей,
отбор по SHA-256 и person_id. Матрица float32, без масштабирования. Параметры:
200 деревьев, max_samples=256, random_state=1901, n_jobs=2. Нужны ≥32 обучающих,
≥24 калибровочных, ≥4 разных вектора; иначе unavailable, без подстановок.

Оценка = −score_samples; чем выше, тем необычнее в пространстве признаков.
IF-процентиль — midrank CDF по calibration. Отдельно rules percentile по
(число факторов, сумма вкладов) на той же calibration; combined = 0.5 IF
percentile + 0.5 rules percentile. Эти оценки не меняют основной рейтинг.

Scoring охватывает все пригодные исходные профили, включая train и calibration;
это ретроспективный unsupervised-анализ представленного набора. Роль каждой
строки сохранена; holdout не участвует в fit/CDF. Это не измеренная способность
предсказывать будущие поездки. Нет меток — нет accuracy/ROC/precision.

Сохраняются модель joblib, версии NumPy/sklearn, параметры, split и scores.
После записи модель повторно читается только собственной сборкой и сверяется
на calibration. Веб-сервер не загружает pickle/joblib и не принимает чужие модели.
