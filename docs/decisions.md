# Решения по уточнению от 17.10.2026

Статус: спецификация и предложения; исполнение и независимая приёмка впереди.
Основание: сообщения заказчика и последнее указание пользователя работать в
`reape/update`, не продолжая T16. Код и результаты расчётов не изменяются.

| Решение | Причина | Следствие для плана |
|---|---|---|
| D01. T16 на паузе | Прямое указание пользователя | Не добавлять конвейер, команду запуска, тесты или изменения конфигураций T16 |
| D02. Учебный персональный сценарий только на полностью вымышленных профилях | История поездок не устанавливает принадлежность человека к «шпионам»; персональное профилирование реальных людей не включается в реализацию | Для реальных данных только агрегаты; смена имени или хеширование не меняют режим |
| D03. Топ по числу независимых критериев | Заказчик хочет выше тех, у кого сработало больше оснований | Основной порядок: число групп ↓, балл правил ↓, стабильный учебный ключ ↑ |
| D04. Максимум 50 подходящих профилей | Прямое уточнение заказчика | На достаточном учебном наборе ровно 50; при нехватке не выдумывать строки |
| D05. Выбор → карта с датами и стрелками | Основной пользовательский сценарий | Все учебные поездки учтены, дата видна на карте, направление сохранено |
| D06. Объяснения из сохранённых расчётов по-русски | Нужны понятные проверяемые причины | Значение, условие, окно и события хранятся вместе с версией правила |
| D07. IF/комбинация — отдельные эксперименты | Старая гипотеза 50/50 не соответствует новому основному порядку | Явный переключатель, сравнение в T20 без скрытой смены сортировки |
| D08. Пропуски и качество не дают положительных голосов | Недоступность признака не равна необычному поведению | Явные маски и статус «Недостаточно данных»; дефекты — в отчёте качества |
| D09. Новые факторы сначала проверяются | Полезность и независимость ещё не измерены | Каталог M01–M07 — предложения, а не принятые индикаторы |

## Открытые вопросы для реализации

Они не мешают зафиксировать требования сейчас и не имеют выдуманных ответов.

| Вопрос | Кто решает / где проверяется |
|---|---|
| Какой полностью вымышленный набор и seed станут приёмочными? | T20, проверяет T21; не менее 50 подходящих профилей плюс крайние случаи |
| Какие группы доступны, какие пороги/веса и минимум покрытия обоснованы? | T15/T17, отдельная проверка T20 |
| Какой минимум размера агрегированной группы и какое укрупнение времени/географии нужны? | T20/T22, блокирует публикацию реальных агрегатов до обоснования |
| Каковы допустимые задержки интерфейса на согласованном компьютере? | Замеры T22/T24 и повторение T29 |
| Какой локальный картографический ресурс и его лицензия войдут в поставку? | T24; работа без сети обязательна |
| Как меняются оценки часов и сроки после новых условий? | Владельцы T15/T17/T20/T22–T24; старый календарь сохранён как история |

Новые задачи T32+ не вводятся. Основной сценарий P0 важнее расширенных
факторов P1, анимации и косметики. Запись предложения в план не означает
его включение в модель. Возобновление T16 требует отдельного указания
пользователя; эта ветка не считается её выполнением.
