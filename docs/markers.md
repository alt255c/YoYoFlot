# Каталог учебных критериев — предложение от 17.10.2026

Статус: **план; критерии и пороги ещё не приняты**. Применяется только к
полностью вымышленным учебным профилям согласно [требованиям](requirements.md).
Каталог не предназначен для обнаружения «шпионов» среди реальных людей.

В T15 сейчас есть девять числовых признаков и метаданные `observed_days`.
Наличие признака не означает наличие готового критерия, корректного покрытия,
принятого порога или работающей модели. Точные существующие формулы перечислены
в [словаре признаков](feature_dictionary.md).

## Предлагаемые группы

| ID / группа | Что описывает | Что уже есть / что добавить | Условия проверки | Приоритет |
|---|---|---|---|---|
| M01 / activity | Интенсивность поездок за сопоставимое окно | Есть `trip_count`, `active_months`, `trips_per_active_month`; нужна проверка полноты окна и опорная группа | Частый учебный деловой путешественник — контрольный пример; активные месяцы не равны полному сроку наблюдения | P0, T15/T17 |
| M02 / quick_return | Частые быстрые возвраты A→B→A | Есть `return_trip_count`, `short_stay_count`; нужны корректный знаменатель и проверка последовательности | Обе точки и порядок известны; доля и количество считаются одной группой; предел 0–2 дня — текущая формула T15, не принятый порог критерия | P0, T15/T17 |
| M03 / repetition | Сильная повторяемость одного направления | Есть `repeated_route_share`; нужен знаменатель только из известных маршрутов | Регулярный учебный маршрут на работу сам по себе не объясняет принадлежность человека; проверить дубли и пропуски | P0, T15/T17 |
| M04 / activity | Всплеск активности относительно собственной учебной истории | Добавить сравнение фиксированных временных окон при достаточной предыстории | Не создавать отдельный дополнительный голос к M01 за тот же всплеск; разрыв загрузки источника не является всплеском | P1, T15/T20 |
| M05 / sequence | Повторяющиеся замкнутые цепочки A→B→C→A | Добавить восстановление цепочек по известным точкам и датам | Не подменять неизвестные участки; не учитывать простые A→B→A повторно в M02; неоднозначный порядок делает пример недоступным | P1, T15/T20 |
| M06 / rarity | Маршруты, редкие в фиксированном учебном наборе | Добавить версию опорной выборки, сглаживание и минимальную поддержку | Опорный набор фиксируется до оценки; единичная ошибка аэропорта не создаёт экстремальный балл | P1, T15/T20 |
| M07 / coflight | Повторные совместные учебные события в разные дни | Требуется T18: события, допустимость связей, число различных дней и сравнение с фоном | Одна поездка или несколько её копий не дают повторной связи; популярность рейса учитывается | P1, T18/T20 |

P0 означает приоритет разработки, а не уже включённый критерий. T17 фиксирует
минимальный пригодный набор после проверки входов; остальное сохраняет статус
`unavailable` или `disabled`. Для включения P1 нужны отдельные результаты T20.

Количество уникальных аэропортов, медианный интервал и число поездок можно
использовать для описания примера, но не превращать каждый связанный счётчик
в дополнительное независимое основание. Каталог явно задаёт `group_id`;
M01/M04 дают максимум один голос группы activity. Другие пересекающиеся группы
пересматриваются по результатам проверки корреляции и общих событий.

## Контракт одного критерия

Планируемая конфигурация каждого критерия содержит:

- стабильные `criterion_id`, `group_id`, версию формулы и русское название;
- требуемые признаки, их единицы, допустимое окно и точность даты/времени;
- минимальное покрытие, состав и версию опорной группы, если она используется;
- оператор сравнения, порог, вес и основание выбора; значения подбираются на
  отдельном учебном наборе и замораживаются до итоговой проверки;
- шаблон русской причины и способ получить подтверждающие учебные `segment_id`;
- статус `enabled`/`disabled` и объяснение отключения.

Результат имеет состояние `matched`, `not_matched`, `unavailable` или `disabled`.
`unavailable` не равен `not_matched`. Нулевое значение допустимо только при
достаточных наблюдениях и вычислимой формуле. Если `value` равно null, критерий
не может быть доступным и сработавшим одновременно.

Группа даёт один голос, если хотя бы один её доступный критерий сработал.
Баллы критериев внутри группы также ограничиваются одним вкладом, например
максимумом; итоговую формулу и веса утверждает T17. Этот выбор проверяется
на устойчивость в T20. Конкретные численные пороги пока не заявляются
обоснованными.

## Русские объяснения

Шаблон: «За {начало}–{конец}: {наблюдаемое значение} {единица}.
Критерий срабатывает при {условие}. Использовано {число} учебных поездок».
Для сравнения с группой добавляются размер и версия группы и её показатель.
Значения берутся из сохранённого результата, а не придумываются при отображении.

Примеры формулировок с условными значениями:

| Состояние | Текст |
|---|---|
| Сработал | «В учебном примере 4 из 8 подходящих возвратов пришлись на интервал до 2 дней. Это выше демонстрационного порога 3; окно: 01.01–31.03.2026» |
| Недоступен | «Быстрые возвраты не оценивались: у части последовательности неизвестен аэропорт отправления» |
| Отключён | «Повторные совместные события пока не оценивались: граф учебного набора ещё не принят» |

Числа в примере — иллюстрация текста, не производственные настройки. В карточке
также показываются обычные объяснения паттерна: рабочие поездки, пересадки,
сезонность, полнота источников. Текст не называет профиль «шпионом».

## Что не включать

Ошибки нормализации, разные написания имени, число паспортов, конфликты
идентичности и нехватка источников — вопросы качества данных. Они не дают голосов
в рейтинге. Имя, документ, гражданство, конкретная страна и предполагаемые
убеждения не входят в признаки. IF не добавляет голос «ещё один критерий»:
это отдельный экспериментальный метод сравнения на учебном стенде.

## Проверка перед включением

Для каждой группы нужны положительный и отрицательный вымышленные примеры,
пограничное значение, недоступный случай и дублированное свидетельство.
Отдельно проверяются обычный частый путешественник, регулярные рабочие поездки
и неполная история. Цель — проверить расчёт и объяснение; эффективность
выявления реальных людей или принадлежностей по этим сценариям не заявляется.
