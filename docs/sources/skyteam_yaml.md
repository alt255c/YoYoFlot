# T09 SkyTeam-Exchange.yaml

Реальная структура: один документ → дата → рейс → {FF, FROM, TO, STATUS}.
FF — словарь с составным ключом `FB 00123` и {CLASS, FARE}. Ключ разделяется
на программу и номер; ведущие нули сохраняются, полный ключ в raw_json. Каждая
карта даёт person с неизвестным именем, identifier и exchange_record со ссылкой
на карту. FARE берётся из её атрибутов, FROM/TO/STATUS из рейса. Полный FF не
копируется в каждую поездку: память/объём не растут квадратично.

CSafeLoader выдаёт события без загрузки гигантского mapping; scalar остаются
строками. В памяти один рейс (100000 nodes, depth50, scalar<=2 млн символов).
SQLite контролирует повтор date/flight, вложенные повторные ключи фатальны.
Anchors/aliases явно отклоняются. Общие дополнительные схемы FF также тестируются.

Полный баланс: 366 дат, 1270920 рейсов, 1687053 карты/поездки, errors=0.
Все STATUS буквально LANDED (1270920). Это статус рейса, без установленного
доказательства посадки конкретного пассажира; event_kind остаётся нейтральным.
Сверены карточки/маршруты/FARE пяти рейсов в разных частях файла. Повторный ключ
не заменяет молча предыдущий. Время и RSS полного прохода: real_runs.json.
