# T03 Skyteam_Timetable.pdf

Поддержанные на исходной искусственной фикстуре шаблоны: cover с Covers period,
FROM: City, CountryIATA TO: City, CountryIATA, строка расписания со слитными или
раздельными значениями и строка с переносами, carry-over секции, codeshare
со звёздочкой/Operated by, consult страницы. Числа страниц/полного времени из
прежней заметки не подтверждены; она сохранена в docs/legacy/ с этим пояснением.

Извлечение совместимо с первым рабочим парсером: page.get_text("text") без
перестановки блоков. Исходный текст всех страниц хранится в page_text.zip;
raw_line восстанавливается по смещениям исходных символов без поиска regex
для каждой строки. Ссылка на архив записана в raw_json.

Неподдержанные кандидаты строк и неизвестные страницы входят в errors и
блокируют complete. Страницы с изображениями без текста сохраняются для
проверки в problem_pages/*.pdf; без OCR проход продолжается. Их расписание
не считается достоверно извлечённым. Ошибки OCR также фиксируются отдельно.
Все страницы прохода записываются в page_coverage.csv. --limit-pages даёт
incomplete при неполном охвате. Cover period определяется из обложки, а не из
константы. Год даты выбирается лишь при единственной дате в явном периоде;
без cover — valid_from/valid_to null. Нет +N → arrival_day_offset null.

Checkpoint связан с SHA-256 PDF, source_id, версиями parser/contract, chunk size,
OCR и page limit. Порции фиксируются атомарно, после interruption продолжаются
с последней завершённой. Изменённый вход/параметры сбрасывают старые части.
Сборка CSV/JSONL/Parquet использует одну порцию, сохраняет null и одинаковые поля.

Команды: `uv run python -m yoyoflot ingest timetable_pdf --chunk-pages 100`,
`uv run python -m yoyoflot audit --rows 50`. Audit заполняет только выборку;
manual_match/reviewer/notes должны быть сверены с PDF человеком. Нужно проверить
≥50 реальных строк из всех шаблонов, включая обе точки, время, дни и период.
Для T11 период расписания сравнивается с датами поездок, маршрут не
экстраполируется на исторические даты за пределами valid_from/valid_to.

Результат фикстуры: 4 страницы, 5 schedules, 0 ошибок; полный реальный файл не
обработан. Тесты: parse/carry/codeshare, interruption, changed input/config,
unknown template, image-only page, typed equivalence, partial page limit.

Пользователь подтвердил корректную работу своего PDF-парсинга. Реальный файл
не передан, поэтому полные замеры/50 строк/период не подменяются фикстурами.

В 0.3.4 восстановлен оригинальный page.get_text("text") без изменения порядка
blocks. Изображения без текста и OCR failures отмечаются в errors/coverage,
сохраняются в problem_pages/*.pdf, проход продолжается с честным incomplete.
Старый рабочий Parquet сохраняется и сравнивается по всем строкам/20 полям.
Совместимость частичного checkpoint проверяется на всех сохранённых текстовых
страницах до продолжения; несовместимый checkpoint сохраняется рядом.
