# T10 YourBoardingPassDotAero.zip

Независимая инвентаризация: 366 XLSX, 615771 лист; каждый лист — одна посадочная
карточка, а не таблица пассажиров. Все листы обработаны, исключений нет.
Крупнейшая книга YourBoardingPassDotAero-2017-12-17.xlsx: 3114 листов, входит в
полный замер. coverage перечисляет каждый лист и boarding_card_v1.

Фактическая раскладка 13×8: B3 имя, F3 карта, H3 класс; A5 рейс, D5/H5 города;
D7/H7 аэропорты; A9 дата, C9 время, E9 оператор; B13 PNR, E13 билет. Проверяются
фиксированные labels BOARDING PASS, SEQUENCE:, GATE, ->, SEAT, PNR:, E-TICKET.
Имя книги не определяет дату поездки. Locator: архив/книга/лист/row:3.
Все исходные cells с координатами, типами и формулами сохранены в raw_json.

Внешний ZIP читается по книгам, одна книга копируется в seekable временный файл.
readers/xlsx_stream.py потоково разбирает OOXML workbook/rels/styles/sharedStrings
и строки sheet через lxml; полная модель книги не создаётся. Cached формула
читается в том же проходе; если cached value нет, поле null с предупреждением.
Дата Excel определяется по стилю/эпохе: дата без времени остаётся датой; дата+
время не получают неизвестный UTC. Числовые ID предупреждаются, нули не угадываются.
Shared strings/styли одной книги занимают память своего размера.

Табличные тестовые XLSX также поддерживаются. Пустые/служебные/неизвестные листы,
не-XLSX, испорченные книги учитываются явно; повтор ZIP имени фатален.
615771 people, 746812 identifiers, 615771 travels, errors=0. Восемь листов из
начала/конца четырёх книг (включая крупнейшую) сверены независимым openpyxl.
Полный пик RSS 210.9 МиБ, время 448.4 с, batch_size=3000.
