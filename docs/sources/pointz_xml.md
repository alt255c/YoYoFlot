# T07 PointzAggregator-AirlinesData.xml

Фактическая структура: PointzAggregatorUsers/user, атрибут uid; name с атрибутами
first/middle/last; cards/card@number вида `FB 00123`, дочерний bonusprogramm;
card/activities/activity с Code, Date, Departure, Arrival, Fare. Имя составляется
из реально присутствующих частей, uid хранится external_id. Карта разделяется
на programme/value, bonusprogramm и полный номер сохраняются в raw_json.
Activity связана именно с родительской картой через loyalty_identifier_id;
полный ordinal XPath сохраняет вложенность. Это loyalty_activity, не доказанная
посадка. Повторы остаются отдельными свидетельствами, паспортов в этой схеме нет.

iterparse освобождает каждого user и удаляет предыдущие элементы; namespaces
не мешают чтению. DTD/сеть/разворачивание внешних сущностей отключены. Ошибка
синтаксиса фатальна, прежний результат сохраняется. Общие варианты user/activities
поддержаны без приписывания каждой активности всем картам.
Полный баланс: 66657 пользователей, 88818 карт, 436090 активностей, errors=0.
Сверены 5 пользователей по всему файлу, их имена, uid, все карты и выбранные
вложенные активности. Замер RAM и итоговые ссылки проверены на полном входе.
