# T06 FrequentFlyerForum-Profiles.json

Реальный корень Forum Profiles — массив. ijson держит один профиль; выход
порционный. Real Name содержит First Name, Middle Name, Last Name; null допустим.
NickName не подменяет имя. Travel Documents — список контейнеров Passports;
в выданном файле все контейнеры пусты. Паспорта не выдумываются. Непустой документ
поддерживается и имеет locator с индексом контейнера и паспорта.
Loyality Programm — список {programm, Number}; programme и number разделены,
внешний пробел Number удаляется, ведущие нули сохраняются, исходник в raw_json.
Registered Flights: Date, Flight, Codeshare, Departure, Arrival и другие поля.
Вложенная география сохраняется как JSON, без догадок о городе/коде аэропорта.

Полный баланс: 66592 профиля, 88827 карт, 1308987 поездок, errors=0.
Профили без рейсов сохраняются. Документы/карты не размножают рейсы; никаких
произвольных связей рейс–паспорт нет. Сверены 5 профилей по всему входу, карты,
первые/последние рейсы и codeshare. Заполненность полей: field_coverage.json.

Дополнительно поддерживаются корневой массив/словарь профилей, варианты полей
карт/документов. Дубликаты внутри профиля отвергаются StrictObject, профильные
ключи контролируются SQLite; root metadata вне Forum Profiles этим не проверяется.
Повреждённый JSON останавливает источник. Огромный отдельный профиль занимает
память своего размера; полный пик данного входа измерен в real_runs.json.
