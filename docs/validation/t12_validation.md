# T12: проверка реализации

192 теста прошли на Linux/Python 3.12. Полный протокол: t12_pytest.xml,
метаданные и область проверки: t12_validation.json. Установленный wheel
0.5.0 проверен на шести персональных фикстурах и PDF; тихий CLI пуст,
результат T12 принимается T11, канонические таблицы сохраняются.

Синтетический benchmark воспроизводится scripts/benchmark_t12.py:
20000 профилей + 20000 карт + 40000 поездок + 80000 provenance =
160000 входных строк, 4.768 секунды, ошибок нет. Это не измерение полного
реального набора и не нативная проверка Windows.

Все критерии карточки проверены семантическими сценариями, но независимая
приёмка полных реальных выходов T05–T10 в этом окружении недоступна.
Карточка остаётся в статусе «реализовано; ожидает приёмки».
