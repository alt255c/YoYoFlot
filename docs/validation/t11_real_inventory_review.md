## Обнаруженная ошибка

Country сравнивался буквально с английской страной OpenFlights. Поэтому
`{"City":"Moscow","Airport":"SVO","Country":"Russian Federation"}` отвергался
при справочном Russia. В инвентаре JSON 1 165 496 вхождений имеют context_conflict;
не все из них безопасно исправлять.

В конфигурацию внесены десять правил: Russian Federation/Russian → Russia,
United States of America/United States of → United States, три варианта
Spain and Canary Islands → Spain, Myanmar → Burma, Lao People's → Laos,
Turks and Caicos → Turks and Caicos Islands. Варианты с усечением проверены только
для данного источника. Правила не восстанавливают отсутствующий код: необходим
явный уникальный код аэропорта, страна которого согласуется с целевой страной.
Строки raw не заменяются; каждое исправление имеет reason/evidence и статус corrected.

Пустой Country игнорируется как отсутствующий контекст. По нему дополнительно
разрешено 3712 точных кодов; они остаются exact, без придуманной страны источника.
Myanmar/Burma встречаются в самом снимке как два написания, поэтому правило имеет
явный reference_name_variant; прежние точные соответствия не заменяются.

## Внешние основания ручных правил

- [UN M49](https://unstats.un.org/unsd/methodology/m49/): названия/коды стран,
  раздел recent changes и прежнее имя Burma для Myanmar (104).
- [Европарламент, внешние регионы](https://www.europarl.europa.eu/factsheets/en/sheet/100/outermost-regions-ors-):
  Canary Islands (Spain).
- Локальный снимок OpenFlights из data/reference; его SHA-256 совпадает с
  указанным в присланном отчёте. Проверенные усечённые варианты — вывод из
  конкретного инвентаря и явных кодов; это не глобальные названия стран.
