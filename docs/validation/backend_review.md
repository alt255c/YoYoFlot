## Операционные действия в тестовом окружении

Тестовый том был ограничен 32 ГиБ. Для завершения вычислений удалялись
завершённые избыточные reader Parquet caches после формирования canonical
и geography, а также закрытые временные файлы T13, уже материализованные
в DuckDB. Производные PDF CSV/JSONL временно сжимались без потерь;
до публикации core они были восстановлены с проверкой исходных SHA-256.
После публикации удалены дублирующие reader/processed work caches.
Семь оригинальных raw-файлов, опубликованные таблицы и параметры модели
этими операциями не изменялись.

Операционные записи `reader_cache_reclamation.json`,
`t13_temporary_reclamation.json`, `published_cache_reclamation.json` и
`processed_cache_reclamation.json` включены в машиночитаемый протокол.
Отдельные действия по месту на диске относятся к условиям этого запуска;
обычная рекомендация остаётся **не менее 50 ГБ свободного места**.
Точное повторение использует immutable snapshot до обращения к work cache;
для изменившегося запроса удалённые промежуточные файлы придётся восстановить
расчётом из исходников. Эта экономия диска не заменяет проверку coverage.

## Найденные и исправленные проблемы

| Проблема | Последствие | Исправление |
|---|---|---|
| Общий перенос маршрута между страницами двухколоночного PDF | Продолжение левой колонки получало маршрут правой; ошибка могла оставаться со статусом `ok` | Независимое состояние колонок, проверка сохранения полного текста, регрессии на страницах исходника |

| Не распознавалось прибытие `+-1` | Пропуск 60 строк расписания | Сохранение явно указанного смещения −1 день |
| Пустые страницы с логотипом считались сканами | Ложные ошибки чтения и неопределённость последующего переноса | Проверка повторяющегося заголовка и полностью белого тела; настоящие сканы по-прежнему требуют OCR/разбора |

## Границы проверки

Автоматические проверки подтверждают работу кода, сохранность исходников и
воспроизводимость расчётов. Они не создают достоверную разметку подозрительности

исследовательскими гипотезами; precision/recall без разметки не заявляются.

на поставленных таблицах и не доказывает этот прогон.
