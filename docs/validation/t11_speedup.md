# T11: ускорение большого прохода

Патч применяется поверх 0.4.0, включая прежнее исправление повторного запуска.
Распаковать в корень проекта с заменой файлов. Зависимости не менялись.

Почему замедлялось:
- Все строки одного номера рейса извлекались и разбирались из JSON заново;
  фильтрация маршрута происходила уже в Python. Кеш 64 номеров часто вытеснялся.
- Индексы по уникальным SHA-256 обновлялись при вставках, создавая случайные
  обращения к растущей SQLite-базе. Маленький кеш усиливал нагрузку на диск.
- Исходные raw_json и другие колонки переводились в Python и обратно в Arrow;
  инвентарь сериализовал одинаковые места для каждой строки вместо агрегации.

Изменения:
- Индекс flight/destination/origin с фильтрацией известных точек до JSON decode.
- Ограниченный объёмом кеш результатов и повторное использование evidence JSON.
- Массовая сборка уникальных индексов, проверка дубликатов до публикации.
- Настроенный кеш SQLite; без journal/fsync только для одноразовой рабочей базы.
  При сбое база отбрасывается, прежние итоговые файлы сохраняются.
- Сохранение исходных колонок непосредственно из Arrow; Python обрабатывает
  только нужные для T11 поля. Уникальные места агрегируются перед сериализацией.
- Прогресс не чаще раза в 30 секунд теперь содержит обработано/всего.
- Исправление OS-lock и Ctrl+C включено; -q остаётся тихим.

Замер без профилировщика: 100000 строк расписания, 40000 поездок, 5000 номеров,
случайные SHA-256; 80000 выходных ссылок. Медианы двух запусков:
14.4618 → 5.4938 секунды (2.63 раза). Все четыре Parquet таблицы совпали по
каждому полю, порядку строк и схеме. 143 теста прошли. Отчёт t11_speedup.json.

Правила выбора маршрута/периода, codeshare, неоднозначности и UTC сохранены.
Это не измерение полного реального набора или Windows; на диске пользователя
ускорение и время могут отличаться. Новые индексы собираются ближе к концу
соответствующего этапа, поэтому возможна пауза после счётчика последней порции.

Применение к уже работающему проходу требует остановки и запуска заново:
checkpoint T11 пока нет. Если текущий проход уже близок к завершению,
можно дать ему закончиться и применить обновление для следующих запусков.

Команда: python scripts/run_t11.py
