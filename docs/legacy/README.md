# Исторические заметки входного репозитория

Это авторские заметки из присланного архива. Заявленные там числа страниц,
периоды/полные измерения в текущей сессии **не подтверждены**: самого датасета
здесь нет. Они сохранены как контекст, а не доказательство приёмки.

`timetable_pdf_original.py` — точная копия первого рабочего кода, также
подтверждённая отдельно присланным пользователем файлом. Используется как
эталон регрессионных тестов; для Run используйте readers/timetable_pdf.py.
