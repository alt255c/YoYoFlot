# Запуск веб-приложения

На Ubuntu из корня проекта выполните `bash build_and_run.sh` для полной сборки
и запуска либо `bash start_web.sh` для запуска уже подготовленного результата.
Адрес: http://127.0.0.1:8501/. Для другого порта: `bash start_web.sh --port 8502`.

## Версия результата

Сервис читает проверенный полный продукт `artifacts/source-product`.
Факторы, веса, связи с исходными записями и рейтинг включены в него. Отдельные
каталоги дополнительных факторов для запуска сайта больше не требуются.
Старый промежуточный T17-продукт нужно пересобрать полной командой.

После изменения `configs/scoring.yaml` выполните `bash build_and_run.sh`.
Сервер откажется смешивать новую конфигурацию со старым рейтингом.
При смене результатов перезапустите уже работающий сервер; его run_id
показывает конкретную версию, которой соответствуют выгрузки.

## Доступ из сети

Приложение обслуживается Waitress. По умолчанию доступно только локально.
Для привязки к внешнему интерфейсу задайте собственный секрет:

```bash
export YOYO_AUTH_TOKEN='your-own-long-random-secret'
bash start_web.sh --host 0.0.0.0
```

Браузер запросит HTTP Basic-аутентификацию: имя `yoyoflot`, пароль — значение
переменной. Для внешней публикации используйте HTTPS на обратном прокси.
API также принимает заголовок `Authorization: Bearer <token>`.
Не сохраняйте секрет в репозитории. Для постоянных браузерных сессий между
перезапусками задайте отдельный `YOYO_SESSION_SECRET`.

## Загрузка и деморежим

ZIP должен содержать полный каталог опубликованного продукта с
`run_manifest.json`, `tables/`, `assessment/` и остальными проверяемыми файлами.
Вложенные манифесты происхождения допускаются. Архив читается с ограничением
размера; все контрольные суммы проверяются перед активацией.

Загрузка набора, деморежим и сброс действуют только в текущем браузере.
Деморежим выбирает первые пять профилей из реального рейтинга и не создаёт
людей, перелёты или метки. Загруженные наборы временные и освобождаются после
завершения работы или истечения неактивной сессии.

## Docker

Сначала соберите данные на хосте. Затем задайте `YOYO_AUTH_TOKEN` и выполните
`docker compose up --build`. Контейнер только обслуживает готовый продукт.
Данные монтируются только для чтения; обучение и обработка raw внутри веба не выполняются.
