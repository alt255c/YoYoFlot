# YoYoFlot Sentinel · веб-морда

Локальный интерфейс работает на проверенном snapshot продукта. Он показывает
топ-50, топ-100 или топ-1000, карточку любого профиля из рейтинга, список всей
популяции с поиском/фильтрами, факторы и карту маршрутов.

## Локальный запуск

```powershell
python -m yoyoflot.product.web --product C:\path\to\source-product
```

Откройте `http://127.0.0.1:8501/`.

Кнопка **Открыть demo-шпионов** выбирает первые пять профилей из активного
реального рейтинга. Новые люди, перелёты и метки не создаются; в интерфейсе
режим помечен как demo-подмножество. Кнопка **Вернуть основной набор** возвращает
полный snapshot.

## Загрузка

Через **Загрузить snapshot** принимается ZIP уже собранного продукта с
`run_manifest.json`. Сервер проверяет manifest, список файлов, контрольные суммы,
пути архива и лимиты распаковки. Браузер не запускает сборку модели и не
принимает произвольные raw-архивы.

API:

- `GET /api/top?limit=50|100|1000` — рейтинг;
- `GET /api/users?limit=60&offset=0&q=...&eligibility=all&sort=rank` — вся популяция;
- `GET /api/profile?id=...` — факторы, evidence, маршруты и IF;
- `POST /api/upload` — ZIP snapshot через multipart/form-data;
- `POST /api/demo` и `POST /api/reset` — переключение режима.

## Docker

```powershell
$env:YOYO_PRODUCT_PATH = 'C:\path\to\source-product'
docker compose up --build
```

После запуска интерфейс доступен на `http://localhost:8501`. Снимок монтируется
в контейнер только для чтения. Docker здесь упаковывает веб-сервис и окружение;
тяжёлый raw-прогон по кнопке загрузки не запускается.
