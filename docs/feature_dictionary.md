# Матрица учебного T19

T19 0.10.0 использует три явных числовых признака T17:
`trip_rate_30_days`, `quick_return_share`, `repeated_route_share`.
Порядок фиксирован конфигурацией, тип при fit/score — float32. Полные
профили с сопоставимыми правилами входят в эксперимент; неизвестные значения
не импутируются. ID, имена, страны и показатели качества не входят в матрицу.

Граф выключен по умолчанию. При явном включении добавляются
`excess_repeated_companions` и `max_positive_pair_excess_days` T18, после проверки
одинакового входа и окна. M07 выключен и не добавляет голос в основном рейтинге.
[Контракт и калибровка](model_card.md#контракт-признаков-и-окна).

# Отдельные учебные признаки T17

T17 0.8.0 использует собственный независимо сгенерированный вымышленный набор,
`profile_id` и три формулы с известным окном и явной доступностью. Они не заменяют
описанные ниже исторические признаки T15 и не читаются из реального T15.
[Формулы, знаменатели и контракт](t17_rules.md#критерии-и-доступность).

# T15 — словарь поведенческих признаков

Единица строки — `person_id` из T13. Источником поездок служат только
`segments.parquet`; документы, имена, паспорта и конкретные страны в признаки
не входят. Даты без `departure_date` не используются в календарных расчётах.

| Признак | Формула | Ограничение |
|---|---|---|
| `trip_count` | число различных `segment_id` | не равно числу свидетельств |
| `active_months` | число месяцев с датой вылета | неполное окно снижает сопоставимость |
| `trips_per_active_month` | `trip_count / active_months` | null при отсутствии месяца |
| `unique_routes` | число известных пар origin → destination | неизвестные точки исключены |
| `unique_airports` | число различных известных аэропортов | неизвестные точки исключены |
| `repeated_route_share` | `1 - unique_routes / trip_count` | null без поездок |
| `median_gap_days` | медиана интервалов между датированными поездками | null менее чем для двух дат |
| `return_trip_count` | соседние поездки B→A после A→B | требует двух известных маршрутов |
| `short_stay_count` | такие возвраты с интервалом 0–2 дня | не выводится из времени без даты |
| `observed_days` | от первой до последней известной даты включительно | это диапазон наблюдения, не полнота источника |

Доступность и число использованных наблюдений находятся в
`feature_coverage.parquet`. Отключённые или недоступные признаки получают
причину, а не нулевое значение.
