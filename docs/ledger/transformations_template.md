# Журнал преобразований

- Задача / автор / дата / версия reader:
- Вход: имя, SHA-256, размер, кодировка, подтверждённая схема.
- Изменение: поля, нормализация, исходные значения, связи.
- Причина: правило контракта/ограничение источника.
- Количество: прочитано, принято, исключено; документы/карты/поездки отдельно.
- Исключения: причины, locators, воспроизводимые примеры.
- Выход: каталог, manifest, версия схемы, команда воспроизведения.
- Проверка: тесты, время/RAM, ручной аудит и reviewer.
