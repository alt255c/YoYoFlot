# T20 — 18.10.2026

Ветка `reape/T20` создана напрямую от `reape/T19` / `23d31a7` по указанию
пользователя. Пакет 0.11.0; новых зависимостей нет, lock меняет только версию проекта.

Добавлено отдельное holdout-семейство с вариацией количества поездок и
контрольными обычными историями. Строгий gate поддерживает его рецепты;
метки сценариев не входят в модель/матрицу. Реальные индивидуальные входы
не подключены. 21 заранее заданный опыт сравнивает правила/IF/комбинацию,
чувствительность и отключение групп, сохраняя основной режим T17.

Метрики учитывают пропуски, общие/парные совокупности, равные баллы и
фактически выбранные строки. Смена окна/наблюдаемой истории не оценивается
старыми метками качества. Для разных ID нет ложного Jaccard/корреляции.
Отдельный oracle пересчитывает сохранённые результаты без production-helper
и десериализации моделей. Снимки и кэш проверяют родителей, состав и хеши.

Проверено 547 тестов (60 новых). Свежий опыт: 21 вариант, 20 инвариантов;
независимый oracle сверил 513 строк метрик. При финальной проверке устранено
неполное связывание runtime: кэш T20 учитывает версии ML-библиотек и требует
точного совпадения runtime родителей T19.

Подготовлена слепая стратифицированная выборка 50 историй с незаполненными
решениями, отдельным ключом и строгим импортом ответов. Заполненные тестовые
фикстуры не являются настоящим независимым ревью. Автоматической приёмки/T21
нет; M07 выключен, IF/комбинация/граф не продвигаются автоматически.
