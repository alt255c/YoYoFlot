# T17 — 17.10.2026

Ветка `reape/T17` создана непосредственно от `reape/T16` / `0f3c311` по
уточнению пользователя. Коммиты T16 не переносились на ветку от develop;
develop, reape/update и reape/T16 не изменяются этой задачей.

Добавлены независимый вымышленный генератор с проверкой воспроизведения строк,
три группы критериев, сортировка по числу групп и баллу, максимум 50 допустимых
профилей, русские объяснения с evidence, отдельные неизменяемые снимки и CLI.
Конфигурация строго проверяется, пороги помечены демонстрационными. M04–M07,
IF, комбинация и интерфейс явно не реализованы. Версия пакета 0.8.0.

Учебные формулы не используют старые реальные признаки T15: у них отдельные
схемы profile_id, известное окно и явные знаменатели/причины недоступности.
Ни исходники T11–T16, ни реальные персональные результаты не подаются в рейтинг.

Тесты проверяют арифметику, группы, поддержку, топ-50, доказательства причин,
порядок дат, входное происхождение, повторяемость, версии снимков, ошибки,
блокировки и запуск из другой папки. Итог и границы проверки — в
[протоколе](../validation/t17_validation.json). Независимое ревью и T20 ожидаются.
