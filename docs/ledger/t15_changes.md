# T15 — числовые признаки поведения пассажиров

Добавлены `src/yoyoflot/features/travel.py`, конфигурация
`configs/features.yaml`, словарь `docs/feature_dictionary.md` и запуск
`scripts/run_t15.py`. Признаки строятся по строке на `person_id` из T13 и
используют только `segments.parquet`: число поездок, активные месяцы,
нормированную частоту, уникальные маршруты и аэропорты, повторяемость маршрута,
медиану интервалов, возвраты и короткие пребывания.

Пропуски времени и маршрута сохраняются как недоступность; нули не подменяют
отсутствие наблюдений. `feature_coverage.parquet` содержит доступность,
количество использованных наблюдений и причину. Имена, документы, паспорта,
страны и идентификаторы не входят в числовые признаки.

Проверки: `tests/test_features.py` — 2 passed. Реальный запуск ожидает
опубликованные `persons.parquet` и `segments.parquet` из принятого T13.
