# T19 — 17.10.2026

Ветка `reape/T19` создана напрямую от `reape/T18` / `4d15d72`, как запросил
пользователь. Слияний develop или повторного переноса T16–T18 нет.

Добавлено настоящее учебное обучение Isolation Forest: отдельные train,
calibration и evaluation, строгая матрица float32, проверка достаточности и
разнообразия, фиксированные seed/параметры, сохранение и повторное чтение
собственной модели. Генератор v2 создаёт более разнообразные независимо
вымышленные истории и ID с seed; v1 остаётся совместимым.

Баллы IF и экспериментальная 50/50-комбинация сохранены отдельно. Процентили
заморожены по calibration; ключ правил сохраняет приоритет числа групп.
Основные rankings/top50 — точная копия T17. Пропуски не импутируются;
недостаточные профили сохраняются с причиной и null. Граф выключен по
умолчанию; явное включение добавляет два признака при совпадении входов/окон.
M07 выключен до T20/ревью, дополнительного голоса нет.

Добавлены `train-if`, `scripts/run_t19.py`, отдельный конфиг и снимки с полным
происхождением. Старые T16/T17/T18 не начинают обучение. Пакет 0.10.0 и
uv.lock согласованы; зависимости уже были объявлены, новых нет.

Проверено 487 тестов (74 новых); независимо сверены сохранённые float32-матрицы,
модели, калибровка и топы на 120/500 оценочных профилях и при включении графа.

Проверки и ограничения: [карточка модели](../model_card.md),
[протокол](../validation/t19_validation.json), [задача](../../tasks/T19.md).
Независимая приёмка, эффективность на новых сценариях и интерфейс ожидаются.
