# Измерения учебного T20

Это короткая публикация проверенного вымышленного опыта, а не полный модельный
снимок. [Выводы](conclusions.md), [автоматический отчёт](evaluation.md),
[метод и запуск](../../docs/evaluation.md).

CSV содержат все результаты предписанного сравнения, устойчивости и парных
абляций. `case_contribution.csv` дополнительно группирует сохранённые баллы
по сценарию/методу для базы, replicate, графа и отключения M01–M03; `selected`
считает фактические заполненные rank ≤ 50, без добавления неподходящих строк.
Это сценарные количества, не индивидуальные характеристики людей.
Для публикации в Git переводы строк CSV приведены к LF; значения и строки
сверены с исходным снимком. Исходные байтовые хеши CSV сохранены отдельно в манифесте.

`report.json` скопирован из полного снимка, `run_manifest.json` этой папки
перечисляет только опубликованные файлы и SHA-256 исходного полного снимка.
Модели, Parquet, исходные родители и закрытый ключ аудита в Git не включены.
Эту папку нельзя передавать как `--input` импортёру ревью: для него нужен
полный снимок из `artifacts/t20/evaluation-<hash>/`.

Воспроизведение: `python scripts/verify_t20_demo.py`. Команда создаёт новый
полный опыт и проверяет сохранённые метрики независимо от рабочего helper,
не загружая существующие модели. Рецепты, параметры и версии связаны
[протоколом](../../docs/validation/t20_validation.json). Численные результаты
сравниваются в закреплённом окружении; побайтовые хеши между разными системами
или окружениями не обещаются.

Подготовлено 50 историй, заполнено 0. Независимое содержательное ревью и T21
ожидаются. Сценарные метрики не являются измерением качества на реальных людях.
