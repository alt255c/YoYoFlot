## Результат

Будущий `docs/core_acceptance.md` с конкретными версиями и решением
`pass`/`fail`, а не устное разрешение. Эта документационная ветка не является
приёмкой модели и не возобновляет T16.

## Проверить

- [ ] Завершённый снимок имеет режим, происхождение, контрольные суммы,
  окно, версии конфигураций, правила и воспроизводимую команду.
- [ ] Учебный набор полностью вымышлен; нельзя подключить реальную историю
  заменой имени или флага. Для реального режима подготовлены только допустимые агрегаты.
- [ ] Основной учебный топ по независимым группам и русские причины приняты T20.
  Артефакты пригодны для всех 50 профилей приёмочного набора.
- [ ] Данные для карты позволяют учесть каждую учебную поездку, точность и пропуски;
  отсутствие координат не маскируется потерей записей.
- [ ] P0 проходит; P1 либо проверены, либо явно отключены с причиной и записанным
  решением о переносе. Отключение не выдаётся за готовый граф/IF.
- [ ] Независимое ревью выполнено и блокеры закрыты. При `fail` перечислены
  владельцы исправлений, а реализация интерфейса ещё не начинается.

T16 остаётся на паузе по указанию пользователя. Не обходить её незавершённость
формальным `pass`; карточки интерфейса пока уточняют будущую работу.
