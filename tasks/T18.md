## Реализация

`features/graph.py`, `graph_demo.py`, `graph_null.py`, `graph_artifact.py`,
`configs/graph.yaml`, `scripts/run_t18.py`, CLI `graph`, два файла тестов.
Реальные персональные входы не принимаются. Сохраняются все учебные сегменты,
допустимость каждого свидетельства, события, участия, рёбра и доступность признаков.
Рейтинг T17 и его M07 не изменяются. Обучение относится к T19.

## Проверяемые критерии

- [x] Граф строится на том же воспроизводимом вымышленном входе, что T17;
  чужие реальные строки с обновлёнными хешами отклоняются.
- [x] Нужен явный экземпляр рейса. Дата/маршрут/номер недостаточны;
  codeshare применяется только по прямому проверенному учебному правилу.
- [x] Дубли источников/сегментов одного участия не добавляют встречи.
  Повторность требует разных дней. Спорные и неполные записи исключены с причиной.
- [x] Ребро раскрывается до событий, участников, наблюдений и исходных сегментов.
- [x] Условный фон сохраняет активные дни/направления и размеры рейсов;
  точная формула, полный перебор и перестановки сверены.
- [x] Популярный общий рейс даёт нулевое превышение над фоном; одно событие
  не создаёт повторность. Семейство статистических проверок не сужено до найденных рёбер.
- [x] Null не превращается в ноль; знак превышения сохраняется;
  очень малый хвост имеет логарифм вместо ошибочного «точного нуля».
- [x] Будущие события не меняют признаки прошлого; порядок строк и повтор
  сохраняют результат. Неподдерживаемый состав группы явно останавливает расчёт.
- [x] `graph_eligible` не фильтрует полный вход для будущей карты.
- [x] Снимки не перезаписываются, сбой/лимиты/Ctrl+C не публикуют частичный выход.
- [x] Lock/export зависимостей согласованы с текущим pyproject и tzdata.
- [ ] Независимое ревью Кирилла, разбор evidence и условий фона.
- [ ] T20: устойчивость, независимые обычные сценарии, проверка порога M07;
  до этого группа остаётся disabled и не добавляет голосов.
- [x] T19: отдельный проверенный контракт матрицы/пропусков/окон перед обучением — [реализован в 0.10.0](../docs/model_card.md).
