## Результат

`python scripts/run_t20.py` выполняет заранее заданные 21 опыт: правила, IF,
комбинация, отдельное семейство вымышленных holdout-историй, повторный seed,
неразмеченный набор семейства training, чувствительность к параметрам,
отключение групп, граф, окно и контролируемые пропуски.

Сохраняются проверяемый снимок, JSON/Markdown, CSV сравнения и устойчивости,
численные признаки и объяснения расхождений. Для ревью подготовлена выборка
50 историй с непрозрачными ID и пустыми решениями. Импорт ответов отдельный,
исходный снимок не изменяется, личность/независимость проверяющего не выдумывается.

## Сделано

- [x] Новое независимое семейство сценариев с фиксированными контролями и тестовыми режимами; каждый вход воспроизводится gate.
- [x] Отделение меток сценариев от training, calibration и числовой матрицы.
- [x] Разные seed и непересекающиеся ID трёх ролей; обучение/процентили остаются контрактом T19.
- [x] AP, ROC AUC, P@10/25/50 и фактические знаменатели общей доступной группы.
- [x] Равные баллы: общий AP/ROC, средние ранги, диапазон P@K на границе.
- [x] Jaccard топов до/после ограничения общей группой, Spearman, изменение покрытия.
- [x] Парное сравнение абляций на одном пересечении профилей; неизвестное не становится нулём.
- [x] Seed леса, число деревьев, размер подвыборки, ±10% пороги, веса 25/75 и 75/25, окно, пропуски и граф.
- [x] Инварианты повторного свидетельства/порядка/префикса окна и неизменности основного режима.
- [x] Отдельный слепой пакет, закрытый ключ выборки и строгий импорт CSV решений.
- [x] Независимый пересчёт сохранённых метрик без вызова производственного helper и без загрузки pickle.
- [x] Воспроизводимые родители, хеши/версии, кэш, lock и повтор после прерывания.
- [ ] Сева: слепой разбор историй и обычных объяснений; фактические решения ещё не получены.
- [ ] Независимая проверка выводов/условий графа и T21 signoff. M07 и интерфейс не включены.

Проверки автора: **547 passed**, 60 новых тестов T20. Свежий полный опыт —
21 вариант и 20 инвариантов; независимо проверены 513 строк метрик. В этой
Linux-среде: 61.928 с после начальных импортов и ещё 3.569 с на независимый
пересчёт. Проверки не заменяют решения человека.

Результаты реализации не доказывают эффективность на неизвестных случаях.
Основным остаётся рейтинг T17 по числу критериев; IF/комбинация/граф не
продвигаются автоматически по результатам holdout.
