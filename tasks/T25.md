# T25. Воспроизводимый backend одной командой

Цель: пользователь запускает `./build_and_run.sh` и получает реальный результат
на исходном датасете преподавателя без ручной сборки окружения и без веб-сервера.

Скрипт создаёт `.venv`, устанавливает закреплённые зависимости, скачивает и
проверяет оригинальный архив, безопасно распаковывает семь источников,
выполняет полный core и аналитический продукт, затем аудит и экспорт.
Локальный оригинальный архив принимается через `--archive`; generated fallback
отсутствует. Ошибки и несовпадения хешей завершают процесс ненулевым кодом.

Приёмка: реальное скачивание с Google Drive, проверка всех хешей, полный raw-run,
проверенный top50 и все его факторы/перелёты, повторный запуск без изменения
исходников и результатов. Код возврата ненулевой при отказе любой стадии;
частичный продукт не выдаётся за готовый. Протокол содержит факты выполненных
проверок, а не предположения о предметной точности модели.
