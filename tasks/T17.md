## Результат

`models/demo.py`, `rule_score.py`, `ranking.py`, `configs/model.yaml`, CLI `train`,
`scripts/run_t17.py` и `tests/test_rule_score.py`. Учебный генератор создаёт
профили с нуля; происхождение входа проверяется повторным получением всех строк.
Реальные персональные таблицы и переименованные/обезличенные реальные данные
не принимаются. Старые выходы T15 и ядро T16 сохраняют свои отдельные контракты.

Три реализованные группы: частота за известное покрытое окно, быстрые возвраты,
повторяемость направленных маршрутов. Основной порядок — число сработавших групп,
затем балл правил, затем стабильный ID. Максимум 50 допустимых профилей с ≥1
срабатыванием. Недостаточные данные и отсутствие срабатываний различаются.
Все значения, пороги, доступность, русский текст и учебные evidence ID сохранены.
M04–M07 явно выключены; IF/комбинация отсутствуют и не добавляют голосов.

## Проверяемые критерии

- [x] Три независимые группы выше двух независимо от веса; одна группа даёт
  максимум один голос, дубли свидетельств не размножают расчёт.
- [x] Перестановка строк, равные баллы и повторный запуск сохраняют порядок
  и детерминированные объяснения.
- [x] Проверены 0/1/49/50/60 подходящих профилей, без дополнения списка.
- [x] Null, неполное покрытие, спорная идентичность, короткое окно и
  неоднозначный порядок событий не превращаются в положительные значения.
- [x] Русский текст содержит окно, значение, условие и поддержку; сохранённые
  ссылки ведут к сегментам того же учебного профиля.
- [x] Реальные и поддельно помеченные входы отклоняются, включая замену строк
  с пересчитанными файловыми хешами.
- [x] Снимки версионируются, проверяются при повторе, не перезаписываются;
  Ctrl+C и конкурирующий запуск проверены.
- [ ] Независимый проверяющий повторил результат и разобрал выбранные причины.
- [ ] T20 проверила чувствительность демонстрационных порогов и альтернативные
  обычные сценарии. Пороги не считаются подтверждёнными признаками реальной личности.

Полный интерфейс, стрелки на карте, T18 и T19 в эту задачу не входят.
