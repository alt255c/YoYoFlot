# YoYoFlot · Catch The Spies

Веб-продукт по исходному датасету преподавателя: топ-50 людей с подозрительными
паттернами поездок → факторы и их вклад → география и хронология перелётов.
Данные не генерируются и не дополняются. Исходные таблицы не изменяются.

## Быстрый запуск

```bash
git lfs install --local
git lfs pull
uv sync --frozen --extra test
uv run --frozen python scripts/run_t17.py
uv run --frozen python -m yoyoflot serve --product artifacts/source-product
```

Сервер по умолчанию слушает локальный порт 8501. `--host 0.0.0.0` нужен только
если требуется доступ к серверу извне машины. Веб-интерфейс и карта работают
без внешних сетевых запросов. Выберите человека слева, изучите факторы,
карточку и перелёты; фильтр дат показывает число скрытых записей.

Снимок `artifacts/source-product` содержит рейтинг, объяснения, признаки,
маршруты, граф, IF, проверку устойчивости и контрольные суммы. Существующий
совместимый снимок проверяется и переиспользуется; несовместимый не перезаписывается.

В `develop` сохранены исходные результаты T13 через Git LFS: 840606 профилей,
2979166 сегментов, даты 2017-01-01–2018-01-01. SHA-256 закреплены в коде
проверки входов. Полные raw-файлы и полная цепочка старых манифестов в Git
отсутствуют; это ограничение сохраняется в продукте. Новые выходы полного T13
принимаются по `resolution_manifest.json`. Никаких fallback-наборов нет.
