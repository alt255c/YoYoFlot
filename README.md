# YoYoFlot · анализ поездок на исходном датасете

Воспроизводимый backend: исходные семь файлов преподавателя → нормализация и
объединение записей → факторы → топ-50 → география и подтверждения по каждому
человеку. Генераторов, дополнения пропусков и подстановки людей в продукт нет.
Исходные байты сохраняются; производные таблицы пишутся отдельно.

Проверка 18.10.2026 получила 840 606 профилей, 2 979 166 сегментов и топ-50
с 1 133 поездками; 8 маршрутов без полных координат сохранены. Прошли 898 тестов
за 156,82 с. Повторное чтение XLSX восстановило coverage всех 615 771 листа
366 книг и точно воспроизвело хеши шести исходных reader-таблиц.
Новый продукт построен на отдельной исправленной ревизии core, числовой аудит
и 53 проверки экспорта прошли. Повтор команды за 124,35 с сохранил байты всех
четырёх контрольных файлов. **Автоматизированная приёмка backend завершена.**
После полного набора тестов дополнительно прошли 4 focused-теста сериализации.
История исправлений сохранена; независимое человеческое ревью остаётся `pending`.
Факты и ограничения: [протокол](docs/validation/backend_review.md),
[машиночитаемый отчёт](docs/validation/backend_validation.json).

## Один запуск

Нужны Bash, Python с модулем `venv` и интернет для первой установки. Проверяемая
версия окружения — Python 3.12; зависимости закреплены в `requirements.txt`.
Для полного прогона планируйте не менее **50 ГБ свободного места**; рекомендуем
**8 ГБ оперативной памяти или больше**. Это запас для промежуточных таблиц,
временных файлов и снимков, а не измеренный предел потребления.

```bash
./build_and_run.sh
```

Скрипт создаёт `.venv`, устанавливает зависимости, скачивает оригинальный
`Airlines-All.zip`, проверяет SHA-256 архива и каждого файла, выполняет полный
конвейер семи источников, обучает Isolation Forest, проверяет результат и
экспортирует отчёт. Веб-сервер не запускается. Git LFS для этого пути не нужен.

Если оригинальный архив уже скачан:

```bash
./build_and_run.sh --archive /path/to/Airlines-All.zip
```

`--archive` исключает скачивание данных; первая установка Python-зависимостей
всё ещё требует доступа к пакетам. Уже установленные исходники проверяются и
используются повторно. Новая версия архива не принимается под старым хешем.

Для ранее опубликованного core доступен `--core-snapshot /absolute/path/to/core`.
Команда проверяет его файлы, происхождение, соответствие текущим raw/config и
полноту XLSX coverage перед построением продукта. Подробности повторного
использования и исправлений: [usage.md](docs/usage.md).

## Результат

| Путь | Содержимое |
|---|---|
| `artifacts/source-product-report/top50.csv` | Место, профиль, количество доступных и сработавших факторов, сумма вкладов |
| `artifacts/source-product-report/factors.csv` | Значение, порог, вес, вклад, причина недоступности, подтверждающие сегменты |
| `artifacts/source-product-report/flights.csv` | Все поездки людей из топа: даты, направления, координаты и исходные статусы |
| `artifacts/source-product-report/profiles.json` | Полные карточки, пригодные для будущего веб-интерфейса |
| `artifacts/source-product-report/report.md` | Читаемый отчёт о методе, охвате и ограничениях |
| `artifacts/source-product-verification.json` | Независимый числовой пересчёт и проверки согласованности |
| `artifacts/source-product/` | Проверяемый снимок таблиц, модели, порогов, экспериментов и происхождения |

Рейтинг сортируется по числу сработавших групп, затем по сумме взвешенных
вкладов, затем по стабильному ID. Недоступный фактор не даёт баллов и не
отменяет остальные пригодные факторы. IF и комбинированная оценка сохраняются
отдельно; они не добавляют скрытый голос в основной рейтинг.

Повторный запуск сверяет исходники и готовые результаты. Совместимые этапы
переиспользуются; чужой или несовместимый снимок не перезаписывается. После
изменения аналитического кода/порогов выберите новый `--output`.

```bash
./build_and_run.sh --output artifacts/experiment-02 --memory-limit 1GB
./build_and_run.sh --help
.venv/bin/python -m pytest -q
```

`--memory-limit` ограничивает DuckDB, а не весь процесс Python. Полный первый
прогон требует существенного времени: архив занимает 477 710 849 байт,
семь исходных файлов — 1 541 640 375 байт (около 1,44 ГиБ), а расписание PDF
содержит 27 514 страниц. Полное время зависит от компьютера и не обещается
заранее. После прерывания повторите команду с тем же `--work-dir`
(по умолчанию `data/work/source-product`): совместимые завершённые этапы
будут проверены и использованы повторно.

Метрики без разметки описывают необычность и устойчивость рейтинга; они не
являются доказанной точностью обнаружения людей определённого класса.
Независимая предметная оценка не подменяется автоматическими тестами.
